# Eco-Type-Forest-Cover-Type-Prediction-Using-Machine-Learning
EcoType is a Machine Learning project that predicts the type of forest cover in a geographical area using cartographic and environmental features such as elevation, slope, soil type, hillshade, and wilderness area information.

📌 Project Highlights
1.Performed Exploratory Data Analysis (EDA) and data preprocessing
2.Handled class imbalance using SMOTE
3.Applied Feature Engineering and encoding techniques
4.Built and compared multiple classification models:
5.Logistic Regression
6.Decision Tree
7.Random Forest
8.KNN
9.XGBoost
10.Achieved best performance using Random Forest Classifier
11.Performed Hyperparameter Tuning using RandomizedSearchCV
12.Developed an interactive Streamlit Web App for real-time predictions
🚀 Model Performance
Best Model: Random Forest
Accuracy: ~95%
